# Getting Help

- **Documentation:** start with the [README](README.md), especially [Troubleshooting](README.md#troubleshooting).
- **Bugs:** open a [bug report](https://github.com/jagoncalves14/retab/issues/new?template=bug_report.yml).
- **Feature ideas:** open a [feature request](https://github.com/jagoncalves14/retab/issues/new?template=feature_request.yml).
- **Security issues:** follow [SECURITY.md](SECURITY.md). Don't post them publicly.

Before opening an issue, check whether a similar one already exists and confirm you're running the latest release.
